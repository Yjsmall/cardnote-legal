一、应用服务

CardNote 免费下载，提供本地 PDF 阅读、书库管理、摘录、手写、OCR、知识卡片及白板功能。您应当拥有使用、导入和处理相关资料的合法权利，不应利用应用侵犯他人权益。

基本阅读及已有内容查看不要求有效高级订阅。年度高级会员用于解锁新的高亮、手写、OCR 和白板编辑／导入操作，具体以购买时应用展示的功能说明为准。AI 服务需要您自行配置服务商及 API Key；年度会员费用不包含第三方 AI 调用费用。

二、订阅周期、价格与免费试用

订阅商品为 CardNote 年度高级会员（商品 ID：cardnote.pro.yearly），每个正常付费周期为1年。中国大陆区当前标准价格为人民币68元／年；其他地区的币种、税费和价格以华为收银台展示为准。

符合华为平台资格的账号可享1个月免费试用。免费试用需要您在华为收银台主动确认自动续费订阅；确认时本期费用为0元。资格由华为判断，已使用过推介优惠或不符合资格的账号按收银台实际展示的价格购买。

免费试用结束后，如未及时取消自动续费，将转为付费年度订阅，按购买页面和华为收银台展示的年度价格自动续费。 当前中国大陆方案为免费试用1个月后68元／年。准确的试用截止时间、扣费时间和适用价格以您的华为订阅管理页面为准。

如应用报价、试用资格或条款与华为收银台不一致，请停止购买并核对；最终购买条件由您在收银台确认。价格发生变化时，相关告知及确认按华为平台规则和适用法律进行，不将旧价格展示作为对未来所有周期价格的永久承诺。

三、自动续费与取消

您授权华为在后续订阅周期按适用价格使用绑定的付款方式处理续费。扣费安排、重试和付款方式验证由华为管理。请保持付款方式有效，并关注华为发送的续费提醒。

您可以从 CardNote「设置 → 会员 → 管理订阅／取消自动续费」进入华为订阅管理；也可从系统「设置 → 华为账号 → 付款与账单 → 订阅」选择 CardNote 并关闭自动续费。具体菜单名称可能随系统版本变化。

如不希望发生下一次扣费，请在华为订阅管理显示的扣费时间之前取消，建议至少提前24小时，并确认平台显示取消成功。取消后，通常可继续使用至当前试用或已付费周期到期；退款、撤销或平台终止的情形，以华为返回的实际有效期及状态为准。卸载应用、删除本地资料或不再使用应用不会自动取消订阅。

四、权益验证、恢复与离线使用

订阅属于购买时使用的华为账号。换设备或重装后，请使用原购买账号并联网执行「恢复购买」；华为平台决定可恢复的权益范围。应用不另建付费账号，不要求您向开发者提供支付密码。

CardNote 使用华为 SDK 查询并校验签名订单及订阅状态，保存成功后确认发货。网络错误可能导致显示或恢复延迟；请联网重试，避免重复购买。

离线高级编辑最多持续至最近一次成功联网查验后的第7天，且不得超过订阅截止时间。退款、取消或账号状态变化在下一次成功查验后同步；离线使用不会自动延长订阅期限。

五、到期、付款失败与已有内容

订阅到期且没有有效续期权益时，文档顶部工具栏不可用，新的高亮、手写、OCR、白板编辑／导入和导出都停止。已有书籍和笔记仍可查看；已受理的保存继续完成。应用不会仅因订阅到期而删除您的本地书籍或笔记。

付款失败、退款或交易撤销后的权益处理依据华为返回的订阅状态及有效期。请及时导出重要资料；设备故障、卸载或清除数据可能影响本地内容。

支付及退款由华为平台处理。可在系统「设置 → 华为账号 → 付款与账单 → 购买记录」进入对应订单，通过页面提供的订单问题或退款入口申请。退款是否批准、到账方式和期限由华为平台规则及适用法律决定。

CardNote 不承诺所有数字商品交易均不可退款，也不限制您依法享有的消费者权利。如遇权益未生效，可先恢复购买，再通过本协议顶部的联系邮箱提供必要的商品名称、问题描述和脱敏订单信息。请不要发送支付密码、完整银行卡资料或 API Key。
